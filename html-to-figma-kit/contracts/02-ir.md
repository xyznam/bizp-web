# 02. IR 추출 계약

**구현: `adapters/extract_ir.mjs`.** 설정(`domContract`)으로 조정하고, 코드는 원칙적으로 손대지 않는다.

```bash
node <키트>/adapters/extract_ir.mjs \
  --html <static>/01_화면명.html \
  --out output/ir/01.json \
  --policy ./board-policy.json
```

## 핵심 계약

| # | 계약 | 이유 |
|---|---|---|
| 1 | 색·간격은 리터럴이 아니라 **토큰 참조**(`{"ref":"--blue"}`)로 싣는다 | Figma Variables에 바인딩해야 색 하나 바꿔 전 화면이 따라오는 구조가 된다 |
| 2 | 역매핑 실패 값은 리터럴 + `unresolved:true`로 **집계한다** | 숨기면 매핑률이 거짓으로 높아진다 |
| 3 | 반복 클래스 시그니처를 `componentCandidates`로 집계 | Component 승격 판단 재료 |
| 4 | 숨겨진 부속 화면(모달·드로어)은 `auxFrames[]`로 분리 추출 | 부속은 별도 보드가 된다 |
| 5 | 프로토타입 전용 블록은 **스크린샷·bbox 측정 전에** DOM에서 제거 | 제거 후 생기는 레이아웃 이동이 좌표에 반영돼야 한다 |
| 6 | 원본 HTML은 무수정 — 제거는 이 페이지의 DOM에서만 | 비파괴 |
| 7 | 텍스트는 **시각적 줄 단위**로 쪼갠다 | 여러 줄을 상자 하나로 내면 Figma에서 다시 줄바꿈되며 원본과 달라진다 |

## DOM 계약 — 화면군별 교체 지점

`board-policy.json` → `extraction.domContract`. **값을 안 채우면 admin-v3 기본값이 적용된다.** 다른 화면군이면 반드시 확인한다.

| 필드 | 무엇인가 | 못 맞추면 |
|---|---|---|
| `contentRoot` | 사이드바·상단바를 제외한 본문 컨테이너 | `main-crop` 프레임이 안 생기고 폼 조작이 화면 전체를 훑는다 |
| `overlayContainers` | 모달·드로어를 감싸는 오버레이 | 열린 모달이 메인 트리를 오염시킨다 |
| `overlayOpenClass` | 오버레이 '열림' 클래스 | 부속 캡처 사이에 이전 모달이 안 닫힌다 |
| `overlayFlexSelector` | 강제 표시 시 `flex`로 되살릴 대상 | 강제 표시한 모달의 레이아웃이 깨진다 |
| `overlayNamePattern` | 딤 배경 요소 식별 문자열 | 캡처에 회색 딤이 비친다 |
| `primaryActionSelectors` | 모달 안 기본 확정 버튼 | 2단계 연쇄 모달에 진입하지 못한다 |
| `formSubmitSelectors` | 본문 폼 제출 버튼 (`{root}` 치환) | 폼 제출로 열리는 확인 모달을 놓친다 |
| `triggerGroups` | 부속을 여는 트리거 후보 (가능성 높은 순) | 부속이 `forced` 모드로만 잡혀 빈 상태로 캡처된다 |
| `namedTriggers` | 특정 auxId 전용 트리거 | 위와 같음 |

**`triggerGroups`에 넣으면 안 되는 것** — 목록을 재렌더해 이후 트리거를 무력화하는 요소(새로고침 버튼 등). 한 번 눌리면 그 뒤 트리거가 전부 실패한다.

## 부속 캡처 모드

| 모드 | 의미 | 품질 |
|---|---|---|
| `trigger` | 실제 트리거를 눌러 연 상태 | **정상** — JS가 주입한 데이터가 채워져 있다 |
| `forced` | `display`를 강제로 되살린 상태 | **주의** — 빈 컨테이너일 수 있다 |

`forced`가 많으면 `triggerGroups`가 화면군에 안 맞는다는 뜻이다. 빈 상태로 캡처된 부속은 보드에 그대로 실리면 안 된다([description-rules.md](../spec/description-rules.md) §1-1).

## 통과 조건

```
□ 토큰 매핑률 ≥ irMappingRateGate (기본 0.9) — 미만이면 중단하고 원인 보고
□ 콘솔 오류 0 · 요청 실패 0
□ auxFrames 수가 화면의 실제 부속 수와 일치
□ auxFrames 중 captureMode='forced' 인 것의 캡처 내용을 육안 확인
□ stripped 개수가 의도한 프로토타입 블록 수와 일치
```

검증: `validate_ir.mjs`는 admin 전용이 아니므로 키트에 포함하지 않았다. 위 조건은 IR JSON의 `stats`·`consoleErrors`·`auxFrames`를 직접 읽어 확인한다.

## 매핑률이 낮을 때

원인 순서대로 확인한다.

1. **CSS가 인라인되지 않았다** — 01-static 미완. 가장 흔한 원인
2. **하드코딩 색이 많다** — 화면군이 토큰 체계를 안 쓴다. 이 경우 매핑률 게이트를 낮추는 게 아니라, 낮은 매핑률을 **사실로 보고**하고 Figma Variables 바인딩이 부분적일 것임을 명시한다
3. **`:root`가 아닌 곳에 변수가 있다** — 스코프 변수. 추출 로직 확장이 필요하다(어댑터 포크 사유)
